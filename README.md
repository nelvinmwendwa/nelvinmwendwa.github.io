# Nelvin Mwendwa — personal site

Static HTML/CSS site. No framework, build step, server or database required.

## Preview locally
Open `index.html` in a browser, or run:
`python3 -m http.server 8000`
then visit `http://localhost:8000`.

## WhatsApp catalogue portfolio demo

The interactive catalogue is published at:

`https://nelvinmwendwa.github.io/catalogue-demo/`

It is a fictional demonstration. Product names, prices, stock and shop identity are sample content. Product photographs are externally hosted third-party references and may be blocked or changed by their owners. Confirm reuse rights or replace them with client-owned/licensed images before commercial deployment.

To test the checkout flow, use a number you control in international digits format (no plus sign):

`https://nelvinmwendwa.github.io/catalogue-demo/?phone=2547XXXXXXXX&shop=Demo%20Shop`

Replace the Xs with the test recipient's number. The page only prepares the WhatsApp message; the customer must press Send in WhatsApp. Never publish a personal number or a client's number without explicit approval.
