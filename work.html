01 · LIVE

Compliance Intelligence Platform

A Kenyan politically exposed persons (PEP) intelligence platform. I built a pipeline that collects public institutional records, parses and normalises them, resolves entities, preserves source citations and stores validated records. The current dataset contains 775 active PEP records across 14 institutions, with 775 source-citation rows. Three state-owned enterprise sources are documented as bot-blocked rather than filled with invented data; county assemblies remain a later phase.

Python · Flask · SQLite · ETL · Entity resolution · REST API

07 · QA CASE STUDY

BizFlow ERP / POS Quality Assurance

Functional QA on a pre-launch ERP/POS system using synthetic records. The register records 110 test cases: 69 passed, 38 failed, 2 not run and 1 blocked, with 45 logged defects across inventory, sales, accounting, tax and reporting. The case study separates observed behaviour from launch-readiness risks and clearly documents the testing boundaries.

Manual QA · Test design · Regression · Defect reporting · ERP / POS
