MatchMint.

A football ticket marketplace concept designed around clear event discovery, structured listings and a straightforward order journey.

01 / Interface

Match discovery

Browse fixture listings with clear event information and pricing tiers.

02 / Backend

Order quoting

A Flask API provides match data and calculates order quotes with quantity and ticket-tier rules.

03 / Data

Relational foundation

PostgreSQL schema covers clubs, matches, listings, orders, payments and delivery records.

Development status: The existing working build includes a React/Vite frontend, Flask backend, PostgreSQL database and demo match data. This page is a public-safe project overview, not a live ticket shop. No tickets are offered for sale here, no payments are processed and no client data or private source code is exposed. A staging demo will be linked only after the project is recovered, secured and approved for external access.
